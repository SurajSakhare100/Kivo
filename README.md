# ✨ Kivo

**Turn your ideas into React applications with AI.**

Kivo is an AI-powered React app builder that transforms natural language prompts into fully functional React applications. Describe what you want to build, watch the code generate in real time, and preview your application instantly — all directly in your browser.

🌐 **Live Demo:** https://kivo.surajx.in/

## 🚀 Features

- **AI-Powered Generation** – Generate React applications using simple text prompts.
- **Live Preview** – See your application running instantly with hot reload.
- **Monaco Code Editor** – Edit your code with syntax highlighting and IntelliSense.
- **AI Chat** – Refine and improve your application through conversations.
- **WebContainer Runtime** – Run a complete Node.js environment directly in your browser.
- **Project Management** – Save projects, create checkpoints, and restore previous versions.
- **Export Code** – Download your generated source code.

## 🛠️ Built With

- React
- TypeScript
- Vite
- Monaco Editor
- WebContainers
- Groq (Llama 3.3)
- IndexedDB

## 💡 How It Works

1. **Describe** – Enter a prompt explaining the application you want.
2. **Generate** – Kivo generates the React application and its components.
3. **Preview** – See your application running in real time.
4. **Refine** – Edit the code or ask AI to make improvements.
5. **Export** – Export your project and use it anywhere.
